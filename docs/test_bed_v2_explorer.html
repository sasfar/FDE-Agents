How to read this

Left: pick a flow. Top bar: pick a scenario. A ✗ scenario ends in a block, and a ⚠ scenario shows a risk. Then press Play.

Map: components this flow doesn't use are faded. The moving dot is the current hop, and its color is the credential it carries. Colored lines are hops already done. Dashed lines are responses. A red ✗ marks where a request is stopped, and an amber ! marks a risk.

Components: 🔑 Auth Provider (policy + vaulted credential, looked up by the broker) · 🛡 Model Armor (called by the ALB authz extension on ingress and by crm-egress-gw on egress) · ⛩ Agent Gateway (crm-ingress-gw, crm-egress-swp-gw, crm-egress-gw). Purple dotted hops are governance links rather than data hops.

Sequence: the same steps as rows, top to bottom. It scrolls itself to the current step. 🔒 marks a component that relays bytes it cannot read, such as the Secure Web Proxy tunnel.

Right: what happens at this step and what to check. The tabs show who has seen each secret so far, which security controls this path has, the full route, and commands to run it yourself.

Bottom: every step of the scenario. Click any step to jump to it.
